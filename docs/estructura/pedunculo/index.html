Pedúnculo

Nivel N1 · forma generalBorrador

Definición

Haz grueso de sustancia blanca que une una parte del encéfalo con otra.

Explicación

Los tres pedúnculos cerebelosos conectan el cerebelo con el tronco encefálico: el superior, con el mesencéfalo y el prosencéfalo; el medio, con el puente; y el inferior, con el bulbo.1, 2 El superior lleva sobre todo fibras eferentes; el medio y el inferior, la mayoría de las aferentes.3

Corteza

Nivel N1 · forma generalBorrador

Capa de sustancia gris que recubre la superficie de una estructura nerviosa.

Explicación

La palabra viene del latín, «corteza de árbol».1 La sustancia gris forma la corteza externa del encéfalo.2 El cerebro y el cerebelo tienen cada uno la suya, plegada para que quepa más superficie en el mismo volumen.1

Corteza

Level N1 · overall shapeDraftTranslation pending: part of this text is in Spanish

Capa de sustancia gris que recubre la superficie de una estructura nerviosa.

Explanation

La palabra viene del latín, «corteza de árbol».1 La sustancia gris forma la corteza externa del encéfalo.2 El cerebro y el cerebellum tienen cada uno la suya, plegada para que quepa más superficie en el mismo volumen.1

Pedúnculo

Level N1 · overall shapeDraftTranslation pending: part of this text is in Spanish

Haz grueso de sustancia blanca que une una parte del encéfalo con otra.

Explanation

Los tres pedúnculos cerebelosos conectan el cerebellum con el tronco encefálico: el superior, con el mesencéfalo y el prosencéfalo; el medio, con el puente; y el inferior, con el bulbo.1, 2 El superior lleva sobre todo fibras eferentes; el medio y el inferior, la mayoría de las aferentes.3

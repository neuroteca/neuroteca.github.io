Núcleo

Level N1 · overall shapeDraftTranslation pending: part of this text is in Spanish

Conjunto localizado de cuerpos neuronales dentro del sistema nervioso central.

Explanation

Es una isla de sustancia gris rodeada de sustancia blanca.1 Cuando un conjunto así está fuera del sistema nervioso central, en la periferia, se llama ganglio.1, 2 No tiene que ver con el núcleo de la célula: es la misma palabra para dos cosas distintas.
